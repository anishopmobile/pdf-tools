# چک‌لیست آزمون دستی روی Windows 10/11 — PDF Tools 1.0.0

> **وضعیت:** تمام موارد زیر **اجرانشده‌اند**؛ این سند برنامه آزمون است، نه گزارش موفقیت. صرف موفقیت Linux pytest یا وجود EXE، جای این آزمون‌ها را نمی‌گیرد.

قبل از شروع، EXE ساخته‌شده `dist\PDFTools\PDFTools.exe` را اجرا کنید و یک پوشه آزمایشی خالی در Documents بسازید. فقط از تصاویر/اسناد آزمایشی بدون اطلاعات شخصی استفاده کنید. برای ساخت PDF آزمایشی می‌توانید با برنامه‌های استاندارد ویندوز از گزینه Print to PDF استفاده کنید.
